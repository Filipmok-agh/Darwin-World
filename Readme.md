### **Jakub Fabia, Filip Mokrzycki**
- Wydział Informatyki, Akademia Górniczo-Hutnicza w Krakowie

- Przedmiot: Programowanie Obiektowe
- Rok akademicki: 2024/2025

## Opis projektu
Celem projektu było stworzenie aplikacji do symulowania i wizualizowania zachowań zwierzaków z prostymi zasadami opisanymi [tutaj](https://github.com/Soamid/obiektowe-lab/tree/a56b132b6f10a73c6df9e9040804f649a894cd3e/proj). 


## Technologie i narzędzia
- **Język programowania**: Java 21
- **Kompilacja**: Gradle
- **Biblioteki**: JavaFX

## Uruchomienie

Klasa odpowiedzialna za uruchomienie programu to [Main.java](/DarwinWorld/src/main/java/agh/ics/oop/darwinWorld/Main.java) znajdująca się w pakiecie src.main.java.agh.ics.oop.darwinWorld
